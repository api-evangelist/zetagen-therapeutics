# Harvest media and select renditions

The site's media library is 388 items and is fully readable anonymously. Every attachment ships its
generated derivatives inline, so you never need a second call to size an image.

## Step 1 — page the library (`listMedia`)

`GET /wp/v2/media?per_page=100&orderby=date&order=desc&_fields=id,date,slug,title,media_type,mime_type,source_url,media_details,post`

- `X-WP-Total` was **388** and `X-WP-TotalPages` **130** at `per_page=3`; at `per_page=100` expect
  4 pages.
- Follow the `Link` header `rel="next"`. Do not exceed `per_page=100` — it returns 400
  `rest_invalid_param`, not a clamp.
- Filter with `media_type=image` or a specific `mime_type` (e.g. `application/pdf`) when you only
  want one class of asset.
- `parent=<post id>` restricts to assets attached to a given release.

## Step 2 — select a rendition (no extra request)

Each attachment carries `media_details.sizes`, a map keyed by size name. Observed on this
deployment:

| size | typical use |
|---|---|
| `thumbnail` | 150×150 square crop |
| `medium` | 300px-wide crop |
| `cmplz_banner_image` | 350×100 crop generated by the Complianz consent plugin |
| `full` | the original upload |

Each entry gives `file`, `width`, `height`, `filesize`, `mime_type` and `source_url`. Pick by
`width` against your target and read `source_url` directly. `source_url` at the top level of the
attachment is always the **full** original.

Not every image has every size — select defensively and fall back to top-level `source_url`.

## Step 3 — one item in detail (`getMediaItem`)

`GET /wp/v2/media/{id}` when you already have an id from a post's `featured_media` field.

`post` is the id of the object the file is attached to, or `null` for an unattached library item.
`alt_text` and `caption.rendered` are frequently empty on this site — do not depend on them for
accessible text.

## Step 4 — embeddable markup (`getOembed`)

`GET /oembed/1.0/embed?url=https://zetagen.com/<path>/&format=json`

Returns a valid oEmbed 1.0 rich response — `title`, `html`, `thumbnail_url`, `provider_name`,
`width`, `height`. Use this when you want a renderable card for a press release rather than raw
content. `maxwidth` defaults to 600.

## Rules

- Media files are served from `https://zetagen.com/wp-content/uploads/...` on the same LiteSpeed
  origin with no CDN in front and no `Cache-Control` on API responses. Do not hammer it — page
  serially and cache on your side.
- These are the company's own copyrighted assets. Reference by URL rather than rehosting unless you
  have permission.
- Portrait images of named individuals are present in this library. Handle them as personal data:
  do not build a people index from filenames or captions. See `skills/_index.yml` exclusions.
- **Do not call `/wp/v2/users`** to resolve the `author` id on an attachment. Excluded on purpose.
